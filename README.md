# پروژه BDD

##  بخش اول: بررسی مشکل Scenario Outline و رفع آن

در انتهای مستند آموزشی مربوط به به‌کارگیری BDD در محیط IntelliJ، هنگام اجرای `Scenario Outline` با خطای زیر مواجه می‌شویم:

```
The step 'Two input values, -1 and 6' is undefined.
```

### علت بروز مشکل:

در کد اولیه، از الگوی Regex زیر استفاده شده بود:

```java
@Given("^Two input values, (\\d+) and (\\d+)$")
```

این الگو تنها اعداد **مثبت** را می‌پذیرد و اعداد منفی (مانند -1) را پشتیبانی نمی‌کند. بنابراین، تست‌هایی که شامل اعداد منفی بودند به عنوان مراحل تعریف‌نشده شناخته شدند.

### راه‌حل:

 روش بهتر استفاده از **Cucumber Expressions** به جای Regex است:

```java
@Given("Two input values, {int} and {int}")
public void twoInputValuesAnd(Integer int1, Integer int2) {
    value1 = int1;
    value2 = int2;
}
```

## بخش دوم: پیاده‌سازی BDD برای مدیریت نوبت‌های کلینیک

###  شرح مسئله:
به عنوان مدیر کلینیک تخصصی، می‌خواهیم نوبت بیماران را با در نظر گرفتن نوع بیمار، وضعیت بیمه، تخصص پزشک و زمان‌های در دسترس مدیریت کنیم تا از تداخل جلوگیری شود.

###  قوانین کسب‌و‌کار:
1. اگر پزشک در تاریخ خواسته‌شده حضور نداشته باشد، نوبت لغو می‌شود.
2. بیمار اورژانسی بدون در نظر گرفتن وضعیت بیمه تأیید می‌شود.
3. بیمار عادی فقط در صورت تأیید بیمه تأیید می‌شود.
4. اگر بیمه رد شده باشد، نوبت لغو می‌شود.

### موارد انجام‌شده:

| مورد | وضعیت |
|:--|:--|
| تعریف فایل feature شامل یک سناریو معمولی |  انجام شد |
| تعریف Scenario Outline با Examples |  انجام شد |
| تعریف Step Definitions برای تبدیل مراحل به کد |  انجام شد |
| پیاده‌سازی کلاس `AppointmentManager` برای منطق اصلی برنامه |  انجام شد |
| اجرای تست‌ها با استفاده از `RunnerTest` |  انجام شد |
| مشاهده پاس شدن همه سناریوها |  انجام شد |

 ##  نحوه اجرای پروژه

### پیش‌نیازها:
- Java JDK (ترجیحاً 17 یا 21)
- Maven

### اجرای تست‌ها:

در root پروژه، دستور زیر را اجرا کنید:

```bash
mvn clean test
```

تمامی سناریوهای تعریف‌شده با استفاده از Cucumber و JUnit اجرا می‌شوند و نتایج در ترمینال قابل مشاهده است.
